# Session Handoff Workflow

Handoff documents preserve exact context when transitioning work across sessions, switching between agents, or coordinating across founder lanes.

---

## When to Create a Session Handoff
Do **NOT** create a handoff after every small routine commit.
Create a handoff **ONLY** when:
1. Ending a session with meaningful unfinished work that another agent or session must resume.
2. Transferring task ownership from Kanuj to Sami (or vice versa).
3. Switching models or agents mid-task.
4. Blocked on an external dependency or the other founder's workstream.
5. A shared interface or schema changed and requires explicit alignment before proceeding.

---

## How to Create a Handoff
1. Copy the structure from [`HANDOFF_TEMPLATE.md`](HANDOFF_TEMPLATE.md).
2. Save it to `docs/agent/handoffs/YYYY-MM-DD-<owner>-<task>.md`.
3. Ensure every section has precise factual entries (commit hash, test results, exact next command).
